How Claude works with this board

Every task and note lives in this page's artifact database, so any Claude session on your account can read and update it. Paste the board's link into a Claude chat and ask it to check the board.

For Claude: use the ArtifactData tool with this artifact's URL. Read tasks and messages; write with set or update. Use ISO 8601 times with an offset.

tasks/<id> {
  title: string,
  notes: string,
  assignee: "sir" | "claude",
  status: "open" | "doing" | "done",
  priority: "high" | "normal" | "low",
  due: ISO string | null,
  remindAt: ISO string | null,
  reminded: boolean,
  tags: string[],
  createdBy: "sir" | "claude",
  createdAt, updatedAt: ISO string,
  completedAt: ISO string | null
}

messages/<id> {
  author: "sir" | "claude",
  body: string,
  taskId: string | null,
  model: string | null,
  createdAt: ISO string
}

Etiquette: pick up tasks assigned to Claude, set status:"doing" while working, then "done" with a note in messages summarising the result.
